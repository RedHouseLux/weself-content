# Agenda e Voglia in 3D (three.js)

Prova di rendering 3D dei personaggi (stile «pupazzi di plastilina»), senza IA.

- Preparazione (una volta): `cd meme/agenda-voglia/3d && npm init -y && npm install three@0.160.0`
- La pagina `personaggi-3d.html` va aperta da un piccolo server locale (moduli ES): Chromium headless con `--use-angle=swiftshader`, poi screenshot quando `window.done` è vero.
- Colori del brand: Agenda #7FD3C8 / #1E9E9E, Voglia #F09B7C con ciuffo #E86F45, dettagli #1E2B5C.
